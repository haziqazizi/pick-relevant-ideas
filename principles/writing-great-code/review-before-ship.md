# review-before-ship

Packaging is not review.

Use before commit, PR, push, merge, release, deploy, or handoff.

## Actions

1. Confirm the current diff matches scope.
2. Confirm generated artifacts are fresh.
3. Confirm evidence is fresh enough for the current diff.
4. Confirm unresolved findings are fixed or explicitly accepted.
5. Confirm rollback/residual notes exist for risky changes.
6. Resolve the inherited scoped receipt; stop if the exact action/target is
   absent. Approval never substitutes for the review and readiness checks above.
