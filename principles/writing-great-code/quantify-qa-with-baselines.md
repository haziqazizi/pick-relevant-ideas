# quantify-qa-with-baselines

Make QA comparable across runs.

Use for browser QA, iOS QA, visual parity, performance, release readiness, and
regression sweeps.

## Actions

1. Capture baseline status or score.
2. Use consistent categories.
3. Record before/after evidence.
4. Separate fixed, new, deferred, and not reproduced issues.
5. Avoid claiming improvement without a comparable baseline.

Categories can be simple: console, network, visual, functional, accessibility,
performance, and content.
