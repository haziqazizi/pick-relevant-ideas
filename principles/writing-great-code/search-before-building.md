# search-before-building

Do not invent unfamiliar infrastructure from memory.

Use when working with libraries, runtimes, browser automation, iOS tooling,
security, protocols, APIs, or product patterns that may have current practice.

## Actions

1. Search local repo precedent first.
2. Use official or primary external sources when recency matters.
3. Separate standard practice from fashion.
4. Prefer existing stable tools over hand-rolled cores.
5. Record source links or local file paths that informed the decision.
