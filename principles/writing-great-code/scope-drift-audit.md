# scope-drift-audit

Compare stated intent against delivered work before judging quality.

Use during review, ship prep, long tasks, and agent-produced diffs.

## Actions

1. Restate the original user objective.
2. List delivered changes.
3. Mark each as in scope, missing, extra, or unclear.
4. Route extras as revert, accept-with-rationale, or follow-up.
5. Route missing items as fix, residual, or explicit out-of-scope decision.

Quality review is premature if the wrong thing was built.
