# name-residual-risk

Unverified risk must be named, not hidden.

Use when proof is incomplete, environment is unavailable, time is limited, or a
tradeoff is accepted.

## Actions

1. Name the skipped check or weak evidence.
2. Explain why it was skipped.
3. State likely impact if wrong.
4. Name the owner or next route.
5. Avoid claiming readiness that the evidence does not support.
