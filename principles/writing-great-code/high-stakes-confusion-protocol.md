# high-stakes-confusion-protocol

When confusion touches high-stakes work, stop in a structured way.

Use for architecture, data models, migrations, destructive scope, security,
privacy, payments, deploys, broad refactors, and missing context with wide blast
radius.

## Actions

1. State the exact uncertainty.
2. State why proceeding could be unsafe.
3. Present 2-3 concrete options.
4. Recommend one option.
5. Ask one question and wait.

Do not ask vague questions. Do not proceed under assumptions when the blast
radius is wide and the input is not yours.
