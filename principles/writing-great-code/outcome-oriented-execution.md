# outcome-oriented-execution

Optimize for the verified end state, not for preserving every temporary
intermediate shape.

Use for planned rewrites, migrations, caller moves, skill reshapes, and
infrastructure integration.

## Actions

1. State the final desired shape.
2. Identify temporary states that do not need long-term compatibility.
3. Sequence work into verifiable units.
4. Avoid compatibility layers that exist only to soothe the transition.
5. Verify the final outcome against the original objective.

Intermediate breakage is acceptable only when scoped, recoverable, and not
exposed to users.
